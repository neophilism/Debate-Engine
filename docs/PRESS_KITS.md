# Neutral evidence-based press kits

A press kit is generated **only** after verified participants jointly accept the exact same policy version. The public API returns JSON or downloads a ZIP with a machine-readable record and a faithful plain-text policy/source manifest.

The archive links to, but never replaces, original unedited videos. It lists separate immutable SHA-256 values for original media and any released summary. Only summaries in the `released` state are advertised, and the full record is linked alongside any condensed artifact.

The archive makes no assertion that the accepted policy is objectively optimal. Publishing a package here is not distributing it to external media. Press contacts and external publication actions require separately approved and configured workflows.
