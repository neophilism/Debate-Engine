# Preserve nonconforming but otherwise safe candidate responses

A verified candidate's technically valid and owner-authorized response is not hidden simply because it is over the symmetric video-duration limit or omitted a reciprocal question. The full unedited video becomes part of the permanent public record and has attributed `format_issues`. The computed qualifying sequence explicitly footnotes it rather than including it.

Hard security/technical limits still apply universally: platform maximum upload size, valid media file structure, verified same-election candidate and authorized branch ownership, no malicious payload or foreign-media impersonation. This does not waive those safeguards. An overlong video that fits the accepted storage/upload limits may be published but is marked nonqualifying.

The engine reports objective format discrepancies (duration and reciprocal question presence) separately from a candidate's subjective responsiveness assessment. A candidate's optional editing consent still does not authorize derivative excerpts. Corrected/replacement public versions require an additional future workflow; the original publication is never removed.
