# Captions and searchable debate transcripts

Candidates can publish conservative WebVTT caption files for their own published source video. Time ranges are validated against the original media duration; HTML cue markup is denied. The record is immutable, and a limited one-caption-per-language/review-state constraint prevents silent replacement.

Published English caption files are attached to the public video player as a browser caption track. Full-text search only covers published transcript text and returns attributed debate/candidate context.

The candidate can declare captions human-reviewed, but the application does not independently attest accuracy yet. Review workflows, multiple revisions, transcript navigation and video-description accessibility remain additional release work.

The default player does not claim that every published media video is captioned until appropriate captions exist.
