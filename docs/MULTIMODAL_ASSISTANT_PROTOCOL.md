# Public Debate Engine — multimodal and private assessment protocol

Authoritative approval details: [development plan](DEVELOPMENT_PLAN.md); [44-unit roadmap](../registry/roadmap.json).

Video is the default and the debate originator can enable audio, writing, or any combination. Each reply chooses one permitted medium. Reciprocal obligations are identical regardless of medium. Public opening rules and media scope are immutable after publication.

The private Debate Assistant never acts as the public answer judge. Draft preliminary assessment -> candidate-controlled changes or rejection -> explicit candidate approval -> immutable public publication -> separate private final assessment. Model variation is normal; results are nonbinding, do not influence qualification, and are not shown to the opponent or public. No scores are public and no simulated AI report may masquerade as a real model result. Remote provider use requires disclosure, consent and configuration.

The actual GitHub repository administrative rename must occur independently from product branding text changes. Keep old links functional until verified by reading live GitHub repository metadata.

Interlocutor is a future separate, thin branded client; it will not operate its own debate-state machine or public-answer tribunal.
