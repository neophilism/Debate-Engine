# Server and database defense in depth

Public debate integrity must not rely on web route authorization alone. Migration 0007 additionally enforces media ownership, candidate membership in the correct election and branch, valid direct-parent reciprocal chains, attributed questions, immediately preceding answer references, assessment authority, opponent objection authority, and participant-only policy proposals and acceptance. It also prevents editing or deleting published policy version records, forbids original-video reuse and checks that derivative approvals concern actual rendered bytes.

These constraints are not proof of independent external attestation, and do not make a privileged database owner incapable of tampering. Production launch still requires role separation, backups, signed receipts and an external preservation audit.
