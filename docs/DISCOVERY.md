# Public participant discovery

Only verified candidacies are listed in the public directory. Profiles display the office, election, affiliation if supplied, and every candidate-published video (including footnoted responses).

This directory is an index of public platform activity, not a platform determination of electoral significance, ballot qualification, fundraising achievement, or policy quality. No engagement-based winner ranking is generated.

Candidate names and affiliations come from records reviewed separately by platform administrators. Account registration alone is not sufficient to appear here.
