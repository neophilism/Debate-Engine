# Independent candidate identity verification and appeals

Registration is not identity verification or endorsement. A new candidacy is marked pending. Only a separately appointed authenticated platform administrator may approve or reject, and the administrator must provide a public procedural reason recorded in an immutable event ledger.

A rejected candidate can file a confidential appeal from their own authenticated account. That changes the claim's state to appealed and returns it to the administrator's review queue. An authorized administrator can read the appeal statement using an authenticated private API. An originating candidate cannot decide whether opponents are genuine candidates merely by originating a debate.

The appeal field is not designed to accept identification documents, government ID numbers or other high-risk personal information. Those require a separate restricted evidence submission process. Do not report this as a finished independently audited identity-verification program; the production process, evidence criteria, appeals personnel and retention policy remain to be adopted.
