# Public qualifying video sequence

The qualifying sequence is a deterministic **projection** over immutable publications; it is not a replacement for the full record. Every branch has its own ordered display of source video players, retaining the original media unedited. Pending and disputed exchanges remain footnoted with links to complete public versions.

This visual sequence uses branchSequence, which requires independently assessed reciprocal answers. An unreviewed question does not silently become accepted. Corrections and old disputed assessments remain in the public archive.

Versioned materialized sequence manifests, third-party integrity attestations and independent copyright authorization still require later release gates.
